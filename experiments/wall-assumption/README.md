# 설계 가정 검증 실험 (2026-11-18, 파일럿)

`BRIEF.md`(작성자 지시서)대로 진행한 A/B 실험이다. 결과와 판단은 `REPORT.md`에 있다.

## 읽는 순서

1. `BRIEF.md` — 원래 질문, 절차, 채점 기준, 채택 기준
2. 아래 ‘진행 중 정한 것’ — 지시서에 없거나 지시서와 달라진 점
3. `cases/*.md` — 사례마다 원문, 기준 시점, 실행 입력, 평가자용 기록(원문 인용)
4. `REPORT.md` — 결과표, 채택 판단, 한계
5. 원자료 — `runs/`, `scoring/`, `repeat-summary-*.json`

## 파일 지도

| 경로 | 내용 |
| --- | --- |
| `cases/{toss,baemin,daangn}.md` | 사례 원본. 실행 입력과 평가자용 기록을 나눔 |
| `make_prompts.py`, `prompts/` | 지시서의 A/B 문장 + 익명 입력으로 만든 프롬프트 6개 |
| `run.sh` | 1회차 실행. 저장소 밖 빈 폴더에서 `claude -p`(도구·MCP·설정 파일 없음) |
| `runs/<case>-<A|B>/` | 1회차 응답 원문, 원본 JSON, 실행 설정(`run-meta.json`) |
| `runs/<case>-<A|B>-r<n>/` | 1~5회차(r1은 1회차 사본) |
| `runs/_leak-check/` | 같은 설정으로 세션이 무엇을 볼 수 있는지 확인한 기록 |
| `make_scoring.py`, `score.sh`, `scoring/score-<case>/` | 1회차 블라인드 채점 키트와 결과 |
| `repeat.py`, `scoring/score-<case>-r<n>/` | 2~5회차 실행과 채점 |
| `scoring/blind-key*.json` | 무작위 ID와 A/B 대응. 채점 세션에는 주지 않았다 |
| `repeat-summary-*.json` | 회차별 점수와 ‘첫날 행동 같음/다름’ 판정 |

## 진행 중 정한 것

| 항목 | 내용 | 정한 사람 |
| --- | --- | --- |
| 당근 사례 | 같은 글의 Project 3(앱 리뷰 자동 라벨링). KAMP·VoC Playground는 관찰한 실패가 원문에 없어 제외. 처음 제시된 ‘신고 처리·희소 항목’ 사례는 받은 원문 두 개에서 확인되지 않아 쓰지 않음 | 작성자 |
| 토스 입력 | “전체 코드를 한 번에 넣기 어렵다”를 A·B 모두에 줌. 되풀이한 답은 ‘실제 문제와 일치’ 0점, 판별력은 따로 채점. ‘실행마다 결과가 달랐다’는 원문 대목을 채점 근거에 붙임 | 작성자 |
| 당근 입력 | 같은 원칙: “키워드 매칭으로는 어렵다”는 입력에 주고 되풀이한 답은 0점 | Claude, 작성자 확인 전 |
| 채택 기준 | 두 사례 이상에서 ① B 판별력 > A ② 첫날 행동이 실제로 다를 때만 후속 검증 제안. 총점·해결책 적중으로 정하지 않음 | 작성자 |
| 반복 | 사례당 5회. 처음에는 “사례마다 5회 중 과반”으로 판단했으나 지시서에 없는 기준이라 외부 검토 뒤 회차별 결과(5회 중 1회 충족)로 고침 | 반복은 작성자 |
| 모델 | 응답 `claude-sonnet-5-5`, 채점 `claude-opus-5-5`. 요금제 사용량이며 API 과금 아님 | 작성자 |
| 격리 | `--bare`는 API 키 인증만 받아 쓰지 않음. 대신 도구·MCP·설정 파일을 끄고 같은 시스템 프롬프트를 씀 | Claude |

## 원문 접근

- 토스·배민: 공개 URL을 curl로 읽을 수 있다(`cases/*.md`의 링크).
- 당근: Medium이 자동 요청을 막는다(403). 브라우저로 열어야 한다.

## 검토를 부탁할 때 볼 것

1. 기준 시점이 맞는가. 실행 입력에 그 뒤에 알게 된 정보가 새어 들어가지 않았는가.
2. 실행 입력과 평가자용 기록이 제대로 나뉘었는가. 원문 인용이 원문과 맞는가.
3. 채점이 기준대로 됐는가. 근거 문장으로 다시 채점하면 같은 점수가 나오는가.
4. 결론(첫날 행동은 바뀌지 않음 → 채택 안 함)이 데이터에서 나오는가.
5. 놓친 한계나 편향이 있는가(원문 기억, B 형식으로 인한 채점자 추측 등).
